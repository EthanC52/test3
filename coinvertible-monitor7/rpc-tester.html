RPC Tester

Tests each endpoint from this browser (same proxy and CORS rules as the dashboard) and prints it in the config.js format. One URL per line; lines starting with # are skipped. The lists start with the endpoints of config.js (if found next to this page) followed by known public candidates. A full run sends about 40-60 small requests per endpoint, spread over a few seconds.
